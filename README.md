# Teitos

Portal de alquiler público asequible: buscador de viviendas, convocatorias y solicitud. Proyecto de aula de PMDM (DAM).

## Instalación

Necesitas Node.js 20 o superior. En la carpeta del proyecto ejecuta: npm install

## Arranque

Ejecuta: npm start
La web queda en http://localhost:5173/ y los datos en http://localhost:3001/
